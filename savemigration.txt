| SAVE MIGRATION LEDGER — retired serialized fields                 |
|###################################################################|
| Every serialized field DELETED from the DLL is listed here, so a  |
| conversion step can match it against existing saves. While the    |
| field is listed, its read site carries a named                    |
| WRAPPER_SKIP_ELEMENT (the IGNORE-by-field-name mechanism) so old  |
| saves that still carry the tag load cleanly; new saves stop       |
| writing it. At the next save-compat break these skips (and this   |
| list's entries) can be flushed together.                          |
|                                                                   |
| ⛔ NEVER delete a WRAPPER_READ outright — a save carrying the tag |
| DESYNCS the whole downstream read (proven 2026-07-02: gutted tech |
| lists + buildingless cities). Read → skip, write → gone, always.  |
